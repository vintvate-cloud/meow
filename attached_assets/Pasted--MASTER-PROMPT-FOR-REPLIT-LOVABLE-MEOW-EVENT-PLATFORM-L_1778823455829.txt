# MASTER PROMPT FOR REPLIT / LOVABLE — “MEOW” EVENT PLATFORM LANDING PAGE

Build a premium SaaS landing page and authentication flow for **Meow** — an event hosting, RSVP, creator-community, and social gathering platform inspired by the emotional energy and playful visual confidence of Linktree’s marketing website, but adapted for a modern event ecosystem similar to Luma.

The website must feel:

* Editorial
* Artistic
* Human
* Confident
* Playful but premium
* Bold without looking startup-generic
* Creative-tech instead of “AI neon SaaS”
* Fashion-brand level polished
* Webby-award quality

Avoid:

* Neon gradients
* Cyberpunk UI
* Generic AI blobs
* Dark mode with glowing borders everywhere
* Glassmorphism overload
* Purple/blue SaaS clichés
* Generic Framer templates
* Overuse of shadows
* Overly minimal sterile Apple clone layouts

The visual language should feel inspired by:

* Linktree’s bold campaign art direction
* Are.na inspired spacing
* Swiss editorial layouts
* Luma’s usability
* High-end fashion campaigns
* Creative community culture
* Youth internet culture
* Modern creator economy products
